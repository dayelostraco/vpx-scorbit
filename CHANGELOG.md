# Changelog

## Unreleased — experimental technical preview

- Shared embedded VBScript decoder/lifecycle, helper bootstrap, entry queue,
  HTTP client and desktop QR policy, plus a hash-guarded offline MM builder.
- Pinned map/parser provenance, helper packaging tooling and optional Python SDK
  experiment. No ROMs, tables, helper executables or device state distributed.
- Input/path validation, snapshot isolation, bounded JSON/QR processing and
  atomic pairing-state updates, with native VBS regressions and offline fuzzing.
- Repeatable Windows tests, per-file Python coverage gates, static/dependency/
  history scans, CI configuration, developer and table-integration documentation.
- MIT licensing for original work, upstream acknowledgments and separate notices.

MM gameplay/uploads and camera scanning remain unqualified; AFM integration and
VR QR presentation are not implemented. Protocol and helper-redistribution
questions remain open. Existing tables do not acquire new embedded code unless
rebuilt and revalidated. See [roadmap](ROADMAP.md) and
[compatibility](docs/compatibility.md) before interpreting these as release notes.
