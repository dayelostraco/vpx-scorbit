# VPX Scorbit project

Read skills/vpx-scorbit/SKILL.md for table integration tasks and docs/research.md
for the pilot's evidence and outstanding dependencies. The adjacent live VPX
installation is not this repository. Follow its installation notes before any
live changes. Keep table binaries, ROMs, captures, credentials and keys external.

Run `python -m unittest discover -s tests -v` after decoder/lifecycle edits.
The SDK adapter is experimental until a matching native SDK and provider
configuration permit real validation. The user explicitly selected the embedded VBScript client and existing
sToken/sQRCode helpers as the default player package. Keep Python/native SDK
requirements confined to optional experiments and developer tooling. Do not publish synthetic scores.
